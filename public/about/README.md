# About-section photo

Drop the factory / showroom shot here as `factory.jpg` (or `.png` / `.webp`,
then update the `<img src>` in `components/sections/Stats.tsx`).

Recommended:
- Aspect ratio ~16:10 (the slot is `aspect-[16/10]`)
- Width ≥ 1600 px so the photo looks crisp on retina at the full panel
  width (~720 px on desktop)
- Showcase the production line, showroom facade or finished installations

While the file is missing the panel shows a stylised placeholder with a
small house icon — nothing breaks layout-wise.
